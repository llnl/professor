# 3D ML visualization

Professor's Dash-based GUI runs as a local web application and displays model
predictions in a browser. It can show orthogonal 2D slices or a 3D volume,
change the Plotly color scale and saturation, and evaluate new predictions as
the model-input sliders move.

![Professor Dash GUI displaying orthogonal slices from a triplane model](images/prof_dash_gui_diffusion_triplane_example.png)

## Check the generated configuration

The training examples pass `--vis-config`, so rank 0 creates
`point_diffusion.yaml` in the run directory. As checkpoints are written, the
configuration is updated to point at the latest one. The same YAML model
configuration can be opened by `prof-dash-gui`.
The autogenerated sliders initially have generic names and bounds. For a
normalized, default three-source dataset, rename them in their existing order
and use bounds from 0 to 1:

```yaml
gui:
  napari:
    fields:
      - concentration
    sliders:
      diffusivity: {lower_bound: 0.0, upper_bound: 1.0, initial_value: 0.5}
      source_0_x: {lower_bound: 0.0, upper_bound: 1.0, initial_value: 0.5}
      source_0_y: {lower_bound: 0.0, upper_bound: 1.0, initial_value: 0.5}
      source_0_z: {lower_bound: 0.0, upper_bound: 1.0, initial_value: 0.5}
      source_1_x: {lower_bound: 0.0, upper_bound: 1.0, initial_value: 0.5}
      source_1_y: {lower_bound: 0.0, upper_bound: 1.0, initial_value: 0.5}
      source_1_z: {lower_bound: 0.0, upper_bound: 1.0, initial_value: 0.5}
      source_2_x: {lower_bound: 0.0, upper_bound: 1.0, initial_value: 0.5}
      source_2_y: {lower_bound: 0.0, upper_bound: 1.0, initial_value: 0.5}
      source_2_z: {lower_bound: 0.0, upper_bound: 1.0, initial_value: 0.5}
```


## Start the web GUI

Start `prof-dash-gui` on the system that can access the checkpoint. It accepts
the same generated YAML configuration used by Professor's visualization
tools:

```bash
prof-dash-gui /path/to/models/point_diffusion_triplane/point_diffusion.yaml
```

Use the voxel run's configuration to inspect that model instead. The default
port is 8888; choose another port when necessary:

```bash
prof-dash-gui --port 8890 \
    /path/to/models/point_diffusion_voxel/point_diffusion.yaml
```

After loading the configuration, the console prints the URL where Dash is
serving the application. For the default port, the relevant output resembles:

```text
Loading config: point_diffusion.yaml
Done!
Dash is running on http://127.0.0.1:8888/

 * Running on http://127.0.0.1:8888
Press CTRL+C to quit
```

From here you can enter the provided URL into your browser.
Once the model is loaded into memory, you will be able to use the sliders on the left-hand
pane to evaluate how each parameter impacts the model outputs.
The active data from the model can either be downloaded as a figure or as an hdf5-format file.


!!! tip

    The web browser needs to be running on the host machine.  If you need to open
    an in-situ brower, we recommend that you first open one in the background:
    (e.g.: "firefox &")
